PDFはA4・各2ページに収まることを実測で確認済みです。開いてそのまま印刷できます。

### HTMLから印刷し直すとき

ブラウザで開いて `Ctrl`＋`P` → **A4・縦／余白なし／倍率100%／「背景のグラフィック」を有効**。
色帯が出ないときは、最後の項目が原因です。

### PDFを作り直すとき

```
chrome --headless=new --no-pdf-header-footer --virtual-time-budget=20000 ^
  --print-to-pdf="出力先.pdf" "file:///.../posters/instructions.html"
```

用紙に収まっているかは、印刷用CSSを画面に適用して要素の高さを測ると確認できます（A4の内寸は 1123px）。

## 決済をページに置いていない理由

紹介ページにも販促ポスターにも、**決済リンクは載せていません**。意図した設計です。

家から買えてしまうと、「買ったのに機械の前にいない」「機械が使用中だった」「その日に来られなくなった」という返金のもとが生まれます。**機械の前に立った人しか払えない**形にすると、これが構造的に起きなくなります。

紹介ページの役割は、売ることではなく**来店の理由を作ること**です。

## 表現について（重要）

当店はジムであり、医療機関ではありません。掲示物・紹介ページとも、**機器の治療効果は書いていません**。

- 「尿失禁が改善します」ではなく、**骨盤底筋を鍛えることについて一般に言われていること**として記載
- 「1回で数千回相当の収縮」などの数値は不記載（別機種の値であり、当店の15分では未検証のため）
- 「医療機器ではない」「体感には個人差がある」「症状の改善が目的なら医療機関へ」を各所に明記

文言を足すときも、この線は越えないようにしてください。
